# Лист — мессенджер

Адаптивный веб-мессенджер с переходом из списка чатов в переписку, созданием групп и каналов, голосовыми сообщениями, а также голосовыми и видеозвонками.

## Возможности

- Вход по номеру телефона через SMS после подключения Supabase Auth и SMS-провайдера.
- Список чатов с поиском и фильтрами «Все», «Группы» и «Каналы». Нажмите на чат, чтобы открыть его переписку.
- Создание групп и каналов. В канале публикует его автор.
- Текстовые сообщения синхронизируются в реальном времени.
- Запись, прослушивание и отправка голосовых сообщений.
- Голосовой и видеозвонок участникам текущего чата. Это браузерное соединение один на один: первым отвечает один участник.
- В демо-режиме используйте код `123456`. Комнаты, сообщения и голосовые сохраняются только в этом браузере; SMS и звонки не работают.

## Подключение общих чатов, SMS, голосовых и звонков

1. Создайте проект Supabase. В **Authentication → Providers** включите **Phone** и настройте SMS-провайдера.
2. В **SQL Editor** запустите весь [`schema.sql`](schema.sql). Скрипт создаёт таблицу чатов, правила доступа к группам и каналам, приватное хранилище голосовых и политики приватных каналов звонков. Его можно повторно запустить в существующем проекте, чтобы применить обновления схемы.
3. В настройках авторизации Supabase добавьте `https://lolkik166.github.io/list-messenger/` в разрешённые адреса перенаправления.
4. В [`config.js`](config.js) заполните `supabaseUrl` и `supabaseAnonKey` значениями из проекта Supabase. Используйте только публичный anon/publishable key. Не помещайте `service_role` или secret key в браузер.
5. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и папку `/` (root). GitHub Pages публикует обновления автоматически.

После настройки вошедшие пользователи увидят общие группы и каналы; создавать их может любой пользователь с подтверждённым номером. Пространства доступны всем участникам проекта — приглашений в закрытые группы пока нет. Голосовые файлы хранятся в приватном Supabase Storage и воспроизводятся по временной ссылке. Звонок инициируется в текущем чате; если несколько человек нажмут «Ответить», соединится первый. Для соединения через некоторые корпоративные или ограниченные сети может потребоваться TURN-сервер.

GitHub Pages обслуживает статический сайт. Бесплатный проект Supabase может приостанавливаться после недели низкой активности, поэтому для непрерывной работы SMS, сообщений, аудио и звонков нужен активный проект или тариф без автоматической паузы.

## Локальный запуск

Откройте `index.html` в браузере для демо. Доступ к микрофону и камере требует безопасного контекста: HTTPS или `localhost`. Для настоящей авторизации запустите сайт через локальный HTTP-сервер, например расширение Live Server в VS Code.
